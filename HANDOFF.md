## 7. La webapp

**En ligne** : https://vuillermozy-cmd.github.io/maroc-2026-carnet/ (GitHub Pages, branche `main`, dossier racine). Chaque push sur `main` republie la page en environ 30 secondes.

**Vercel** : pas encore fait. Il faut se connecter sur vercel.com/new avec le compte GitHub `vuillermozy-cmd`, choisir « Import » sur ce dépôt, puis « Deploy » sans réglage.

**Fichier unique** : `index.html`, sans build ni dépendance. Seules les polices Google Fonts (Bricolage Grotesque et Atkinson Hyperlegible) sont chargées de l'extérieur. L'icône est un drapeau marocain en SVG intégré.

**Structure du script** (en bas de `index.html`) :
- `P` : les lieux (`n` nom, `lat`/`lon`, `q` pour la recherche Google Maps, `lbl` = [dx, dy, ancrage] pour placer l'étiquette sur la carte, `minor` = sous-titre).
- `GEO` : les vrais tracés routiers par jour (`d21`, `d22`, `d23`, `d24`, `d26`), en tableaux de `[lon, lat]`. Ils viennent du routeur public OSRM (router.project-osrm.org), qui utilise les données OpenStreetMap, et sont simplifiés avec l'algorithme de Ramer-Douglas-Peucker (tolérance 0,0007°). Pour `d23`, l'aller-retour est réduit au seul aller. Pour recalculer : `tools/routes.py`.
- `DAYS` : un objet par jour, avec les champs `date` (et `dateEnd` pour la période du 16 au 20 regroupée), `title`, `where`, `stay` (clé de `P`), `south`, `wow` (réveillon), `geo`, `drive` {`from`, `to`, `km`, `min`, `route`: clés de `P` pour le lien Google Maps}, `high` (temps forts dans le tableau du programme), `sleep` [texte, statut `ok`/`todo`, libellé], `park` (voiture et parking), `sched` [[heure, texte, "car" pour un créneau en voiture]], `alerts` (HTML autorisé).
- Les totaux de km et de temps sont calculés à partir de `DAYS[].drive`.

**Fonctions** :
- Compte à rebours, puis « Jour X / 11 » pendant le voyage.
- Tableau du programme.
- Carte SVG, avec les vraies routes, un relief dessiné à main levée et des boutons par jour, dont un seul bouton pour le 16 → 20. Choisir un jour zoome la carte et affiche **uniquement** ce jour, heure par heure, juste en dessous.
- Section « Conduire dans le Sud ».
- Notes par jour.

**Notes** : sur la page publique, elles sont enregistrées dans le navigateur (localStorage), donc par téléphone, sans partage. Le code tente d'abord `window.claude.use("db")`, qui ne servait que dans la version claude.ai. Sur GitHub Pages, ça échoue sans bruit et passe au stockage local. On peut retirer ce code, ou le remplacer par un vrai stockage partagé (Supabase, Firebase…) si Yann et Flore veulent partager leurs notes.

**Thème** : clair et sombre selon le téléphone. Les couleurs sont des variables CSS sur `:root` : indigo pour les routes, ocre pour le Sud et le jour sélectionné.

**Pistes d'amélioration** :
- Vrai stockage partagé pour les notes.
- Mode hors ligne : service worker, pratique dans les gorges où le réseau est faible.
- Fond de carte réel : tuiles OpenStreetMap avec Leaflet, possible sur GitHub Pages.
- Liens vers les hébergements, une fois réservés.
